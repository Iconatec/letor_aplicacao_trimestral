## Organização das pastas

Selecione a pasta raiz que contém as pastas dos bancos.

Cada pasta de banco deve conter uma subpasta chamada `Aplicação`, com os respectivos extratos em PDF dentro dela.

### Exemplo de estrutura

```text
Pasta raiz/
├── 001. Caixa Econômica/
│   └── Aplicação/
│       └── extrato.pdf
├── BB/
│   └── Aplicação/
│       └── extrato.pdf
├── Bradesco/
│   └── Aplicação/
│       └── extrato.pdf
├── Itau/
│   └── Aplicação/
│       └── extrato.pdf
├── Safra/
│   └── Aplicação/
│       └── extrato.pdf
├── Sicredi/
│   └── Aplicação/
│       └── extrato.pdf
└── XP/
    └── Aplicação/
        └── extrato.pdf
```

### Nomes aceitos para as pastas dos bancos

- `001. Caixa Econômica`
- `BB`
- `Bradesco`
- `Itau`
- `Safra`
- `Sicredi`
- `XP`

> A subpasta deve ser chamada exatamente `Aplicação` ou `Aplicacao`.
